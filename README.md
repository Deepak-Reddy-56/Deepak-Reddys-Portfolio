# Deepak Reddy — Portfolio

A retro-pixel inspired developer portfolio built with React, TypeScript and Vite. The visual direction uses a near-black canvas, neon-lime accents, pixel-art details, terminal-inspired panels and scroll-led sections.

## Local development

\`\`\`bash
npm install
npm run dev
\`\`\`

## Production build

\`\`\`bash
npm run build
\`\`\`

The app is a static Vite site and can be deployed directly to Vercel.
